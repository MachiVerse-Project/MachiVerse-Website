# 南雲澪 Web用アセット

このディレクトリは、MachiVerse公式サイト上で「現実側のシステム開発者」として登場する南雲澪の公式Web用イラストを配置するための予約領域です。

## 想定ファイル

- `nagumo-mio.webp`
  - 透過または背景を分離しやすい立ち絵を推奨
  - 一般向けトップページの開発者クレジット、および「開発者ノート」で使用可能
  - 南雲澪はMachiVerse世界内の住民やダイバーではなく、こちら側でシステムを設計・開発している人物として扱う

## サイト上の扱い

主役と主語はMachiVerseのままにします。南雲澪をページ全体の案内役・ナレーターにはせず、システムを実際に開発している人物として、次の程度の存在感で扱います。

- ファーストビュー: 小さな開発者クレジットとして名前を表示
- 中盤: 開発思想を補足する「開発者ノート」
- 現在地: Alpha 1.0の位置づけを補足する短い開発メモ

挨拶、連続した一人称の語り、章ごとの案内、プレゼン形式の説明は行いません。

公式イラストが未配置の現在もページが成立するよう、`hero-developer-portrait` と `developer-note-portrait` は `hidden` にしています。イラスト追加後は、用途に合わせて片方または両方の `hidden` を外してください。

`assets/images/site/optional/character-lifestyle.webp` はダイバーや世界内住民のイメージ用であり、南雲澪の代替画像として使用しません。
