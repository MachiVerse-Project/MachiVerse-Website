# 南雲澪 Web用アセット

このディレクトリは、MachiVerse公式サイト上で「現実側のシステム開発者」として登場する南雲澪の公式Web用イラストを配置するための予約領域です。

## 想定ファイル

- `nagumo-mio.webp`
  - 透過または背景を分離しやすい立ち絵を推奨
  - 一般向けトップページの「開発者より / Developer's Note」で使用
  - 南雲澪はMachiVerse世界内の住民やダイバーではなく、こちら側でシステムを設計・開発している人物として扱う

## サイト上の扱い

南雲澪をページ全体の案内役・ナレーターにはしません。主役と主語はMachiVerseのままにし、南雲は開発思想や設計意図を補足する開発者コメントとして限定的に登場させます。

公式イラストが未配置の現在もページが成立するよう、`developer-note-portrait` は `hidden` にしています。イラスト追加後は `index.html` / `index-en.html` の該当要素から `hidden` を外し、公式アセットを表示してください。

`assets/images/site/optional/character-lifestyle.webp` はダイバーや世界内住民のイメージ用であり、南雲澪の代替画像として使用しません。
