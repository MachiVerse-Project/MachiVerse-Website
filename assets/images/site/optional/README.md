# Optional visual assets

このフォルダには、現時点ではWebページから参照しない予備ビジュアルを配置します。

9・10の画像は生成済みです。GitHub接続側で画像バイナリを直接コミットできないため、以下のファイル名で手動配置してください。

## 9. Character / lifestyle concept

- File: `character-lifestyle.webp`
- Purpose: ダイバーや住民の存在感を補助する人物中心のコンセプトアート
- Direction: 主人公然としたヒーロー表現ではなく、街・自然・生活圏の中にいる一住民として描く
- Avoid: ロゴ焼き込み、強いSF装置、宇宙・惑星、過度なファンタジー、UIオーバーレイ
- Size: 1920x1080

## 10. Alternate landscape concept

- File: `landscape-alt.webp`
- Purpose: 風景主体の別パターン。将来のヒーロー背景、告知、セクション背景などの候補
- Direction: 山・水・街・集落・交通などが同じ世界の中に連続して存在し、世界の広がりが伝わる風景
- Avoid: 未来都市だけを主役にする構図、宇宙的なSF表現、ロゴ焼き込み、派手なホログラム
- Size: 1920x1080

## Usage rule

この2枚は現時点ではページから直接参照しません。使用を決めた時点で用途とトリミングを確定します。ロゴが必要な場合は `assets/images/brand/` の公式ロゴを別レイヤーとして使用します。
