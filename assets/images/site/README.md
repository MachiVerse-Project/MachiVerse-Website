# Website visual assets

このフォルダには、MachiVerse公式Webサイトの一般向け・開発者向けページで使用するビジュアルを配置します。

## 必要ファイル

| File | Purpose |
| --- | --- |
| `social-general.png` | 一般向けトップページのOGP / SNSプレビュー |
| `social-developer.png` | 開発者向けページのOGP / SNSプレビュー |
| `hero-general.webp` | 一般向けトップページのヒーロー背景 |
| `hero-developer.webp` | 開発者向けページのヒーロー背景 |
| `teaser-world-start.webp` | 特報 / 世界起動セクション背景 |
| `concept-connected-world.webp` | 一般向けページの世界接続コンセプト図 |
| `architecture-overview.webp` | 開発者向けページのアーキテクチャ補助図 |
| `template-development-update.png` | Development Update告知用テンプレート |

## Brand rule

これらの生成ビジュアル自体にはMachiVerseロゴを焼き込みません。ロゴが必要な表示では、`assets/images/brand/` の公式ロゴアセットを別レイヤーとして使用してください。

ページ側は上記ファイル名を参照する前提で実装します。
