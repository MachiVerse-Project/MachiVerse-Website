# Web配信用画像アセット

このディレクトリには、MachiVerse公式Webサイトで使用する配信用の画像アセットを配置しています。

公式ブランドアセットの原本は、`MachiVerse-Project/MachiVerse` リポジトリの `promotion` ブランチにある `assets/images/` です。

Website側の画像は原本の代わりではなく、Webサイトで実際に配信・参照するためのコピーとして管理します。

## 収録ファイル

| Website側 | 原本 |
| --- | --- |
| `brand/logo-primary.png` | `assets/images/brand/MachiVerse_Official_Logo_Primary.png` |
| `brand/logo-symbol.png` | `assets/images/brand/MachiVerse_Official_Logo_Primary_Symbol.png` |
| `icons/favicon.png` | `assets/images/icons/Icon (Resize tin).png` |
| `social/og-image.png` | `assets/images/social-preview/Social preview (Cut and resize, comp).png` |

## 更新方針

- ブランドアセットをWebsite側だけで独自編集しないでください。
- ロゴやアイコンの原本を変更する場合は、本体リポジトリの `promotion` ブランチを先に更新してください。
- Website側では、サイトで必要な配信用アセットだけを保持します。
- MachiVerseの名称、ロゴ、その他のブランド識別子の利用条件は、リポジトリルートの [`TRADEMARKS.md`](../../TRADEMARKS.md) を参照してください。
