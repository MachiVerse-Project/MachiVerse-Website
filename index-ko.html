SYSTEM DEVELOPMENT
ALPHA 1.0 / RUNNING VERTICAL SLICE

설계만 있는 것이 아닙니다.
실제 컴포넌트가 끝까지 연결됩니다.

현재 develop 브랜치에는 Simulation Core, Gateway, General View, Administration View를 실제로 연결한 재현 가능한 vertical slice가 있습니다. UI는 아직 Alpha 품질이지만 실제 통신, 권위 있는 상태 확정, 동기화, 영속화, 복구까지 구현되어 있습니다.

ACTUAL CONNECTED FLOW / ALPHA 1.0
01 / BROWSER General View

실제 브라우저 세션에서 세계 상태를 보고 최소 Diver 조작을 보낼 수 있습니다.

02 / EDGE Gateway

외부 연결, 인증·인가, Operation 집계, confirmed cache, publication을 담당합니다.

03 / AUTHORITY Simulation Core

authoritative WorldState를 소유하고 Operation을 실행·확정하는 권위 원본입니다.

04 / OPERATIONS Administration View

실제 브라우저 E2E에서 health와 Config read / change까지 확인되어 있습니다.

대규모 Resident / economy / governance scenario와 polished UI는 Alpha 1.0 다음 work package입니다. 아직 확립되지 않은 규모나 성능 수치는 미리 제시하지 않습니다.

02 / HOW THE WORLD MOVES

세계를 놓아두는 것이 아니라, 세계가 만들어지는 과정까지.

물이 있다. 사람이 모인다. 일이 생긴다. 길이 놓인다. 도시가 된다. MachiVerse는 결과만 나열하지 않고 상태가 어떻게 변하며, 그 변화가 다음 상태에 어떻게 남는지를 다룹니다.

사람자연사회경제도시역사
STATE t그 시점의 세계 상태환경, 주민, 관계, 배치 등
CAUSEOperation과 상호작용세계 규칙 안에서 변화가 일어남
STATE t+1다음 상태가 확정됨같은 세계의 연속으로 상태가 갱신됨
HISTORY변화가 역사로 남음현재가 다음 미래의 조건이 됨
신의 시점이 아니라 세계 안에서.

Alpha 1.0에서는 최소 참여 조작이 General View → Gateway → Simulation Core로 전달되고, confirmed state가 다시 View로 돌아옵니다.

03 / DIVER

세계를 보는 사람에서, 세계 안에서 살아가는 사람으로.

사용자 역할 “Diver”는 세계 밖에서 자유롭게 배치하는 관리자가 아니라, 세계의 시간·규칙·사회적 관계 안에 존재하는 한 주민으로 참여하는 경험을 장기 방향으로 삼고 있습니다.

Alpha 1.0은 그 장기 경험 전체를 구현한 단계는 아닙니다. 현재 연결된 범위는 참여 조작이 실제 컴포넌트를 통과해 authoritative WorldState에 반영되는 최소 루프까지입니다.

04 / CURRENT STATE

Alpha 1.0. 동작하는 기반은 있지만, 완성된 세계는 아직 아닙니다.

현재 local Alpha profile은 개발과 integration을 위한 loopback-only 구성입니다. MachiVerse는 장기 비전을 이미 완성된 것처럼 표현하지 않고, 구현된 동작과 향후 작업의 경계를 구분해 공개합니다.

✓ 현재 구현됨

  • 네 컴포넌트의 실제 end-to-end 연결
  • General / Admin View browser E2E
  • FULL / DELTA state synchronization
  • 최소 Diver Operation
  • Persistence, restart, recovery, resync

→ 다음 work package

  • Core observability / telemetry
  • performance / soak harness
  • multi-Gateway failover / View churn
  • production OIDC / TLS acceptance
  • 대규모 Resident / economy / governance scenario
PRIMARY ACTION

Alpha 1.0은 로컬 환경에서 실행해 볼 수 있습니다.

Windows와 .NET SDK 10.0.400 상당 환경에서 start-alpha.bat로 네 컴포넌트를 한 번에 시작하고 두 View를 열 수 있습니다.
