世界を完成品として置くのではなく、状態・因果・相互作用・時間・歴史をつなぎ、 「なぜ現在の世界がこの状態になったのか」まで説明できる動的な世界を目指しています。

02 / HOW THE WORLD MOVES

世界を置くのではなく、世界ができるまでを。

水がある。人が集まる。仕事が生まれる。道ができる。街になる。 MachiVerseは、結果だけを並べるのではなく、状態が変化し、その変化が次の状態へ残っていく過程そのものを扱います。

人自然社会経済都市歴史
STATE tその時点の世界状態環境・住民・関係・配置など
CAUSE操作と相互作用世界のルールの中で変化が起きる
STATE t+1次の状態が確定する同じ世界の続きとして状態が更新される
HISTORY変化が履歴として残る現在が次の未来の前提になる
神視点ではなく、世界の中から。

Alpha 1.0では最小の参加操作がGeneral View → Gateway → Simulation Coreへ届き、確定状態がViewへ戻ります。

03 / DIVER

世界を見る人から、世界の中で暮らす人へ。

利用者ロール「ダイバー」は、世界の外から自由に配置する管理者ではなく、世界の時間・ルール・社会的関係の中に存在する一住民としての参加体験を目指します。

現在のAlpha 1.0では、その将来像すべてではなく、参加操作が実コンポーネントを通ってauthoritative WorldStateへ反映される最小ループまでが接続済みです。
