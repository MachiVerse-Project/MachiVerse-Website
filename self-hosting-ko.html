먼저 자신의 환경에서
세계를 실행하기.

이 페이지는 개발 참여 전에 MachiVerse를 먼저 실행해 보고 싶거나, 자신의 PC 또는 관리 중인 테스트 머신에서 현재 상태를 확인하고 싶은 사용자를 위한 안내입니다. Alpha 1.0은 4개 컴포넌트가 연결된 로컬 integration profile로 실제 실행할 수 있습니다.

SYSTEM DEVELOPMENT

01 / BEFORE START

‘온프레미스에서 시험하기’와
‘production 운영’을 구분합니다.

현재 local Alpha profile은 개발 및 integration용 loopback-only 구성입니다. 자신의 PC, 검증용 장비, 관리 중인 서버에서 MachiVerse의 현재 상태를 체험할 수는 있지만 production security profile을 대신하지 않습니다.

현재는 외부 공개를 전제로 하지 마세요

production OIDC / TLS deployment acceptance는 Alpha 1.0 이후 작업 항목입니다. 인증, TLS, 공개 설정을 독자적으로 추가한다고 해서 production-ready가 된다고 보장할 수 없습니다.

SUITABLE FOR

  • Windows PC에서 Alpha 1.0 실행
  • 자신이 관리하는 테스트 머신에서 동작 확인
  • 4개 컴포넌트 연결과 UI 실제 확인
  • restart / recovery / resync 테스트

02 / QUICK START — WINDOWS

세 줄로,
실행까지 진행합니다.

현재 본체 저장소의 Quick Start는 Windows용입니다. .NET SDK 10.0.400 상당과 최신 develop을 전제로 합니다.

git checkout develop
git pull
start-alpha.bat

이미 빌드했다면 다음부터는 빌드를 생략할 수 있습니다.

start-alpha.bat --no-build

START-ALPHA.BAT

스크립트가 수행하는 작업

  • .NET SDK 확인
  • 4개 컴포넌트 Release build
  • Simulation Core 시작 및 health 대기
  • Gateway 시작 및 Core Synced 대기
  • General View / Administration View 시작
  • 두 View를 브라우저에서 열기

03 / WHAT STARTS

Core만이 아니라,
4개 컴포넌트를 함께 실행합니다.

표준 Alpha 1.0 시작에서는 Simulation Core, Gateway, General View, Administration View를 연결해 사용합니다.

Simulation Core권위 있는 WorldState / Simulation / Persistence
GatewayAuth / Cache / Operation / Publication
General View일반 사용자용 브라우저 UI
Administration View운영・Config용 브라우저 UI

LOCAL DATA

.machiverse-alpha/

로컬 world / Gateway 영속 데이터가 이 디렉터리에 저장됩니다. 검증 환경을 새로 만들 때도 이 디렉터리를 고려해 주세요.

04 / PERSISTENCE & RECOVERY

한 번 실행하고 끝이 아니라,
재시작도 시험할 수 있습니다.

Alpha 1.0에서는 Core / Gateway persistence, 정지, restart, recovery, resync까지 연결되어 있어 현재 복구 경로를 확인할 수 있습니다.
