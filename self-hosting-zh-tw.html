SYSTEM DEVELOPMENT

01 / BEFORE START

把「自架測試」與
「production 營運」分開看。

目前 local Alpha profile 是供開發與 integration 使用的 loopback-only 架構。可以在自己的 PC、測試設備或受管理伺服器上體驗目前的 MachiVerse，但不能取代 production security profile。

目前請勿以前提為對外公開

production OIDC / TLS deployment acceptance 是 Alpha 1.0 之後的工作項目。目前也沒有保證只要自行補上認證、TLS 與公開設定，就能視為 production-ready。

SUITABLE FOR

  • 在手邊 Windows PC 啟動 Alpha 1.0
  • 在受自己管理的測試機確認運作
  • 實際查看四個元件與 UI 的連接
  • 測試 restart / recovery / resync

02 / QUICK START — WINDOWS

三行指令，
走到啟動。

目前主專案的 Quick Start 以 Windows 為主，需具備相當於 .NET SDK 10.0.400 的環境與最新 develop。

git checkout develop
git pull
start-alpha.bat

如果已完成 build，之後可以略過重新編譯。

start-alpha.bat --no-build

START-ALPHA.BAT

腳本會執行

  • 確認 .NET SDK
  • Release build 四個元件
  • 啟動 Simulation Core 並等待 health
  • 啟動 Gateway 並等待 Core Synced
  • 啟動 General View / Administration View
  • 在瀏覽器開啟兩個 View

03 / WHAT STARTS

不只 Core，
而是一整套四個元件。

標準 Alpha 1.0 啟動會連接 Simulation Core、Gateway、General View 與 Administration View。

Simulation Core權威 WorldState / Simulation / Persistence
GatewayAuth / Cache / Operation / Publication
General View一般使用者瀏覽器 UI
Administration View營運與 Config 瀏覽器 UI

LOCAL DATA

.machiverse-alpha/

本機 world / Gateway 的持久化資料會保存在這個目錄。重建測試環境時也要留意此目錄。

04 / PERSISTENCE & RECOVERY

不只啟動，
也能測試重新啟動。

Alpha 1.0 已連接 Core / Gateway 的 persistence、停止、restart、recovery 與 resync，可以檢查目前的復原流程。
