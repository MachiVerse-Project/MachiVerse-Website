CURRENT STATUS / ALPHA 1.0

Beyond design documents.
Not a finished product.

The current develop branch contains a reproducible Alpha 1.0 vertical slice connecting Simulation Core, Gateway, General View, and Administration View. It includes real Core–Gateway gRPC, browser Views, confirmed FULL / DELTA WorldState publication, a minimal Operation path, persistence, restart, recovery, and resynchronization.

About deployment

The current local Alpha profile is loopback-only for development and integration. Production OIDC / TLS deployment acceptance is still future work, so Alpha 1.0 should not be treated as an internet-facing production profile.

WHAT WORKS NOW

  • Real Simulation Core ↔ Gateway gRPC
  • Real General View / Administration View browser sessions
  • Confirmed FULL / DELTA publication
  • Minimal Diver Operation and authoritative Core mutation
  • Core / Gateway persistence, restart, recovery, and resync
