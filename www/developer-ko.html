기술자설계 사상상위 사양

CURRENT STATUS / ALPHA 1.0

설계만 있는 것은 아니다.
하지만 완성판도 아니다.

현재 develop에는 Simulation Core / Gateway / General View / Administration View를 실제로 연결한 재현 가능한 Alpha 1.0 vertical slice가 있습니다. Core–Gateway 실제 gRPC, 브라우저 View, confirmed WorldState FULL / DELTA 배포, 최소 Operation, persistence, restart, recovery 등이 연결되어 있습니다.

외부 공개에 대하여

현재 local Alpha profile은 loopback-only 개발・integration용입니다. production OIDC / TLS deployment acceptance 등은 이후 작업이므로 현재 Alpha를 인터넷 공개용 production profile로 취급하지 마세요.

WHAT WORKS NOW

  • Simulation Core ↔ Gateway 실제 gRPC 연결
  • General View / Administration View 실제 브라우저 세션
  • confirmed world FULL / DELTA publication
  • Diver 최소 Operation 및 Core 상태 갱신
  • Core / Gateway persistence, restart, recovery, resync
