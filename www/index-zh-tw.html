這座城市，
為什麼會在這裡
也能成為模擬的一部分。

讓人、社會、經濟與自然在同一個世界中一起變化的開源代理人式世界模擬器。 以 C# / .NET 10 開發。

MachiVerse 不把世界當成已完成的佈景，而是把狀態、因果、互動、時間與歷史連接起來， 讓「為什麼現在的世界會成為這個樣子」也能從一路累積的變化中被理解。

SYSTEM DEVELOPMENT
ALPHA 1.0 / RUNNING VERTICAL SLICE

不只是設計。
實際元件已經可以跑完一整圈。

目前的 develop 分支包含一個可重現的 vertical slice，實際連接 Simulation Core、Gateway、General View 與 Administration View。 UI 仍是 Alpha 品質，但通訊、權威狀態確定、同步、持久化與復原都已經接通。

ACTUAL CONNECTED FLOW / ALPHA 1.0
01 / BROWSER General View

實際瀏覽器 session，可查看世界狀態並送出最小 Diver 操作。

02 / EDGE Gateway

負責外部連接、認證授權、Operation 彙整、confirmed cache 與 publication。

03 / AUTHORITY Simulation Core

持有 authoritative WorldState，執行並確定 Operation 的權威來源。

04 / OPERATIONS Administration View

已透過實際瀏覽器 E2E 驗證 health 與 Config read / change。

02 / HOW THE WORLD MOVES

不是把世界擺在那裡，而是讓世界一路形成。

有水。人開始聚集。工作出現。道路形成。城市逐漸成形。 MachiVerse 關注的不只是結果，而是狀態如何改變，以及這些變化如何延續到下一個狀態。

人自然社會經濟城市歷史
STATE t此刻的世界狀態環境、居民、關係、配置等
CAUSEOperation 與互動變化發生在世界規則之中
STATE t+1下一個狀態被確定同一個世界延續並更新狀態
HISTORY變化留下成為歷史現在成為未來的前提
不是上帝視角，而是從世界裡面參與。

Alpha 1.0 中，最小參與操作已能從 General View → Gateway → Simulation Core，之後 confirmed state 會回到 View。

03 / DIVER

從觀看世界的人，走向生活在世界中的人。

使用者角色「Diver」的長期方向，是作為一名存在於世界時間、規則與社會關係中的居民參與，而不是從世界外任意配置事物的管理者。

Alpha 1.0 還沒有實作這個未來體驗的全部。目前已接通的是最小循環：參與操作穿過實際元件，最後反映到 authoritative WorldState。

04 / CURRENT STATE

Alpha 1.0。已經有能運作的基礎，但還不是完成的世界。

目前的 local Alpha profile 是 loopback-only，用於開發與 integration。MachiVerse 會把已實作的內容與未來工作分開呈現，而不把長期願景描述成已經完成。

✓ 目前已實作

  • 四個元件端到端實際連接
  • General / Admin View browser E2E
  • FULL / DELTA state synchronization
  • 最小 Diver Operation
  • Persistence、restart、recovery、resync

→ 下一批 work package

  • Core observability / telemetry
  • performance / soak harness
  • multi-Gateway failover / View churn
  • production OIDC / TLS acceptance
  • 大型 Resident / economy / governance scenario
PRIMARY ACTION

Alpha 1.0 可以先在本機環境中執行。

在 Windows 與 .NET SDK 10.0.400 相當版本的環境中，start-alpha.bat 可以一次啟動四個元件並開啟兩個 View。
