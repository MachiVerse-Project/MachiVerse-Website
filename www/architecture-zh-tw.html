MACHIVERSE / ARCHITECTURE & DESIGN

為了讓世界彼此連結，
把邊界清楚分開。

MachiVerse 不把世界視為靜態狀態的集合，而是具有因果與歷史的動態系統。為此，權威世界狀態、外部連線、使用者顯示與系統營運被分成不同責任，再透過 Protocol 連接。

SYSTEM DEVELOPMENT

01 / DESIGN PRINCIPLES

不只描述世界「現在是什麼」，
也處理「為什麼會變成現在這樣」。

MachiVerse 的核心不是單純增加表面功能數量，而是把世界中的元素以因果關係連起來。都市、居民、自然環境與社會關係並非固定完成品，而是由過去狀態與選擇累積成現在，現在的變化也會留到未來。

CAUSALITY & HISTORY

現在具有歷史

WorldState 不只是一個時間點的外觀，而是從過去延續至今的變化結果。

DETERMINISM

把可重現性當作契約

相同 World Seed、simulation-affecting Config、有效 Operation 集合與順序、套用 Step，應得到相同的邏輯世界結果。

SEPARATION

分離責任

Core、Gateway、General View、Admin View 作為獨立執行、build 與發佈單位。

PROTOCOL FIRST

以 Protocol 作為邊界

不以內部型別或共用 DTO DLL 作為跨元件契約，而使用 versioned Protocol / schema。

02 / TOP-LEVEL COMPONENTS

分成四個單位，
但仍然是一個世界。

程式碼、build、發佈與執行單位都相互獨立，元件不直接呼叫其他元件內部方法，只透過 Protocol 協作。

Simulation Core權威 WorldState / Simulation Step / Operation / Persistence
GatewayAuth / Cache / Mediation / Publication / Resync
General ViewDiver / Spectator / Browser UI / Prediction
Admin ViewHealth / Log / Metrics / Config / Operations
正本在 Core。Gateway cache 與 View 顯示狀態都是衍生狀態。

General View 與 Admin View 不直接連到 Core。Gateway 承擔外部連線、認證授權、cache、Operation 彙整、publication 與 resync 等責任。

項目標準設計意義
世界狀態正本僅 Simulation CoreGateway cache、View 顯示狀態與 prediction 都是非權威的衍生狀態。
標準拓樸Simulation Core 1 / Gateway 1:NGeneral View / Admin View 經由 Gateway 連線；標準 Protocol 沒有 Core↔Core 通訊。
權威時間整數 Simulation Step與社會曆法及時鐘不同；標準計算頻率為 30Hz，並可由外部 Config 調整。
決定論相同重現條件得到相同邏輯結果處理速度、OS scheduling、thread 完成順序、Gateway 數量與 network 到達競爭不應決定 world outcome。
通訊邊界Versioned Protocol / schemaMajor 不相容時拒絕連線；同一 Major 的新 Minor 設計上維持向後相容。
Config各 component 擁有自己的外部 Config區分 simulation-affecting Config 與 display / ops-only Config，並在明確安全邊界套用。
View prediction非權威、presentation-only即使 Diver 操作使用 local prediction / correction，最終仍要 reconcile 至 Core 確認狀態。

04 / AUTHORITATIVE OPERATION FLOW

操作可以預測，
最終由 Core 確定。

General View 可以使用 local prediction / correction 提升操作即時感，但 prediction 並不是正本，必須與經 Gateway、Simulation Core 確認的狀態 reconcile。

General View
   ↓
Gateway
   ↓ auth / authorization / mediation
Simulation Core
   ↓ authoritative apply
confirmed WorldState
   ↓
Gateway → View reconciliation

BOUNDARIES

  • 未授權 Operation 不送往 Core
  • Operation ID 跨 retry / reconnect 維持不變
  • 同一 Operation 不重複套用到世界
  • Core 決定最終有效套用 Step
  • View prediction 不是正本
