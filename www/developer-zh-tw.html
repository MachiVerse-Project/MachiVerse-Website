CURRENT STATUS / ALPHA 1.0

不只是設計，
但也還不是完成版。

目前的 develop 已包含可重現的 Alpha 1.0 vertical slice，實際連接 Simulation Core、Gateway、General View 與 Administration View。Core–Gateway gRPC、瀏覽器 View、confirmed WorldState 的 FULL / DELTA 發布、最小 Operation，以及 persistence、restart、recovery 等流程都已接通。

關於對外公開

目前的 local Alpha profile 為 loopback-only 的開發與 integration 用途。production OIDC / TLS deployment acceptance 仍屬後續工作，因此請勿把目前 Alpha 當作可直接公開到網際網路的 production profile。

WHAT WORKS NOW

  • Simulation Core ↔ Gateway 實際 gRPC 連線
  • General View / Administration View 實際瀏覽器 session
  • confirmed world 的 FULL / DELTA publication
  • Diver 的最小 Operation 與 Core 狀態更新
  • Core / Gateway 的 persistence、restart、recovery、resync
