CURRENT STATUS / ALPHA 1.0

設計だけではない。
でも、完成版でもない。

現在のdevelopには、Simulation Core / Gateway / General View / Administration Viewを実接続した、再現可能なAlpha 1.0 vertical sliceがあります。 Core–Gateway間の実gRPC、ブラウザView、confirmed WorldStateのFULL / DELTA配信、最小Operation、永続化・再起動・recoveryなどが接続されています。

公開用途について

現在のlocal Alpha profileはloopback-onlyの開発・integration用です。production OIDC / TLS deployment acceptanceなどは今後の作業であり、現時点のAlphaはインターネット公開用のproduction profileとしては想定していません。

WHAT WORKS NOW

  • Simulation Core ↔ Gateway の実gRPC接続
  • General View / Administration View の実ブラウザセッション
  • confirmed world の FULL / DELTA publication
  • Diverの最小OperationとCoreでの状態更新
  • Core / Gatewayの永続化、restart、recovery、resync
