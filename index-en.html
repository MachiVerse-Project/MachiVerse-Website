An open-source, agent-based world simulator where people, society, economy, and nature evolve inside the same world. Built with C# / .NET 10.

Instead of placing a finished world, MachiVerse aims to connect state, causality, interaction, time, and history so the present can be explained as the result of what came before.

The current develop branch contains a reproducible vertical slice connecting Simulation Core, Gateway, General View, and Administration View. The UI is still Alpha-quality, but real communication, authoritative state, synchronization, persistence, and recovery are implemented.

02 / HOW THE WORLD MOVES

Not placing a world. Letting a world become itself.

Water. People. Work. Roads. A city. MachiVerse is interested not only in results, but in the process where state changes and those changes persist into what comes next.

HISTORYChange persists as historythe present becomes a condition for the future
Participate from inside, not from a god view.

In Alpha 1.0, a minimal participation operation already travels General View → Gateway → Simulation Core, then confirmed state returns to the View.

03 / DIVER

From watching the world to living inside it.

The participant role, “Diver,” is intended to exist as one resident inside the world's time, rules, and social relationships rather than as an administrator that freely places things from outside.

Alpha 1.0 does not implement that entire long-term experience yet. What is connected today is the minimum loop where a participation operation crosses real components and updates authoritative WorldState.
